# Data

**Synthetic, on purpose.** This is the model answer for a demo course, so the repository has
to be self-contained. `src/data.py` generates 600 municipality-years from a documented
process with seed 2026; nothing is downloaded and no personal data exist.

- **Source:** generated by `src/data.py` (see the docstring for the generating process)
- **Licence / terms of use:** none required - synthetic
- **Collection period:** notional 2025 reporting year
- **Unit of observation:** one municipality in one reporting year
- **Retrieved on:** n/a
- **How to obtain it:**

```bash
python -c "from src.data import load_data; print(load_data().head())"
```

A real submission must replace this file with the provenance of real data: source, link,
licence, collection period, and a script that fetches it. Raw data stays out of the
repository (`data/raw/` is git-ignored).
